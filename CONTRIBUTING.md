# Contributing

This repository is for **cloning and forking only**. I do not accept pull requests, and I may close any that arrive without comment.
Issues are not monitored either. If you want a change, fork the repository and keep it: the licence (MIT) lets you do whatever you like with your copy.

The code is small on purpose. Extraction profiles are meant to be rewritten for your own newsletters, so most useful changes are yours alone.
